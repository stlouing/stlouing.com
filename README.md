# St. Louing

- [stlouing.com](https://stlouing.com)

A personal website documenting the food, neighborhoods, and culture of St. Louis.

## Stack

- **[Astro](https://astro.build)**
- **[Leaflet](https://leafletjs.com)** + **[Protomaps](https://protomaps.com)** (`.pmtiles`) over **[OpenStreetMap](https://www.openstreetmap.org/)**
- **[GitHub Pages](https://docs.github.com/en/pages)**
- **[GoatCounter](https://www.goatcounter.com)**

## Develop

```sh
npm install
npm run dev      # local dev server
npm run build    # production build → dist/
npm run preview  # serve the build locally
npm run prettier # format
```

Requires Node `>=22.12`.
